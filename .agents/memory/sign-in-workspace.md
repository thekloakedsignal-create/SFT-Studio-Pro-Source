---
name: Sign-in workspace
description: Desired initial project state after sign-in or account creation.
---

New sign-ins and accounts should open a fresh, unlocked project state.

**Why:** The user explicitly requested this instead of arriving in a locked existing project.

**How to apply:** Start with an editable draft and no active batches or QA report. Keep saved projects available for explicit selection; do not delete them or automatically reopen them.

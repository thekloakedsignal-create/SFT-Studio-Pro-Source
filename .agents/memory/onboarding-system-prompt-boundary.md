Do not change or replace the onboarding generation system prompt without explicit user approval.

**Why:** The user explicitly identified this prompt as the most off-limits part of the app because it governs golden-example generation and onboarding output.

**How to apply:** Diagnose format problems by inspecting output parsing, model routing, and request handling first. Ask before editing the onboarding system prompt.
